# +++ Features
This mod lets you assign hotkeys for the various menus:
 - Barber shop.
 - Commissary.
 - Contracts.
 - Crafting menu.
 - Credits vendor.
 - Expedition Mode.
 - Havoc Mode.
 - Mission Board.
 - Premium Store.
 - Shrine Penitentax.
 - Social menu.
 - Solo Play Mode.
 - Training Grounds.

Use hotkeys in the Mourningstar, Psykhanium, and even during Solo Play missions (requires SoloPlay mod).
Enable or disable hotkeys in specific areas via mod options.
Close menus by pressing the same hotkey again (toggleable).


# +++ Notes
- Solo Play hotkey requires the "SoloPlay" mod to be installed and enabled.
- All hotkeys are configurable in the mod options (F4 by default).


# +++ Manual Installation
1. Unzip and place the folder named "menu_hotkeys" into your "mods/" directory.
2. Add "menu_hotkeys" to "mod_load_order.txt".

# +++ Incompatibilities
Expeditions Hotkey -- The function of opening the Expeditions view will be duplicated.
Hub Hotkeys -- The function of opening views of different menus will be duplicated.
